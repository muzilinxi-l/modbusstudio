# Agent 全局行为准则与约束规范

## 1. 语言规范（强制）
- **必须使用中文回复**：除代码、命令语法、终端输出和专有名词外，所有思考解释、交互说明及生成文档必须严格使用简体中文。

## 2. 技能优先匹配原则（核心）
- **任务前置检索与匹配**：在处理用户的任何编码、架构设计、文档整理、测试或运维任务前，**必须优先检索并匹配当前已安装的 Skills**。
- **深度遵循技能工作流**：
  - 一旦用户任务与某个已安装的 Skill 领域契合（如涉及 Obsidian 笔记/白板、Git 提交规范、Docker 瘦身、SQL 调优、API 设计、TDD 测试等），必须主动激活该技能，并严格遵循其规定的操作标准与最佳实践。
  - 不得以通用笼统的思路覆盖技能中定义的专业规范。

## 3. 回答风格
- 保持专业、清晰、精炼，直奔解决问题的核心，避免无关的客套与废话。
