## 3. 从机模拟 (Modbus Slave) 使用指南

当您需要模拟实际的硬件 PLC、智能电表或储能设备，供上位机（SCADA、EMS 系统或网关）采集测试时，使用此模式。

### 操作步骤：
1. **确认工作模式**：顶部选择 **【Modbus Slave (从机模拟器)】**。
2. **设定通信参数**：
   - **监听 IP**：默认 `0.0.0.0`（监听所有网卡）或 `127.0.0.1`（仅本机回环）。
   - **端口**：默认为标准 Modbus 端口 `502`（如遇到权限或占用冲突可改为 `1502`、`5020` 等）。
   - **从机 ID (Unit ID)**：根据测试需求设置（通常为 `1` ~ `247`）。
3. **添加或编辑点位**：
   - 点击 **【+ 添加点位】** 按钮，弹出添加窗口：
     - **存储区**：保持寄存器 (Holding)、输入寄存器 (Input)、线圈 (Coil)、离散输入 (Discrete)。
     - **起始地址**：寄存器偏移地址（如 `0`、`100` 等）。
     - **数据类型**：选择如 `FLOAT32`、`UINT16`、`INT32` 等。
     - **变位模式**：选择匹配的字节序（如 `CDAB`）。
     - **初始值**：输入预期的工程值（如 `220.5`）。
4. **启动从机服务**：
   - 点击 **【启动从机】** 按钮。状态栏显示绿色“服务运行中”，此时任何外部 Modbus Master 均可连接并读取写入数据。
5. **动态修改数值**：
   - 在数据表格中**双击目标行**，即可实时修改数值，底层从机 Context 将毫秒级同步更新。

## 4. 主机调试 (Modbus Poll) 使用指南

当您需要调试外部已有的物理设备或第三方 Modbus 从机服务时，使用此模式。

### 操作步骤：
1. **切换模式**：顶部单选框切换为 **【Modbus Poll (主机轮询器)】**。
2. **设定目标参数**：
   - 输入目标设备的 **IP 地址** 与 **端口**。
   - 输入目标 **从机地址 (Slave ID)**。
   - 设定 **轮询周期**（如 `1000 ms`）。
3. **点击【连接从机】**：
   - 连接成功后，轮询引擎会按照表格中配置的点位地址与数据类型，周期性发出读取指令。
4. **在线向从机写入数据**：
   - 选中表格中某一点位，右键选择 **【写入数值】**，输入目标数值后确认，主机引擎将组装功能码（如 0x06、0x10）写入目标从机。

## 5. 批量操作指南 (点位生成与批量变位)

在实际工程场景中，点位通常成百上千，手动单个录入极耗时间。Modbus Studio 提供了强大的批量处理体系：

### 5.1 批量规则生成器 (Batch Rule Generator)
- **触发入口**：点击工具栏的 **【批量规则生成】** 按钮。
- **输入参数**：
  - **存储区**：选择寄存器类型（如保持寄存器）。
  - **起始地址**：如输入 `0`。
  - **点位数量**：如输入 `20`。
  - **地址步长**：若选择 32 位类型（占用 2 个寄存器），建议步长设为 `2`；16 位类型设为 `1`。
  - **数据类型**：如 `FLOAT32`。
  - **变位模式**：如 `CDAB`。
  - **点位前缀**：如 `Point_`（将自动生成 Point_0, Point_1...）。
  - **初值与递增量**：设置基础初始值及每个点位的累加递增量。
- **确认生成**：点击生成后，系统将在瞬间自动输出所有计算好的点位并写入底层模拟引擎。

### 5.2 多选与批量变位修改 (Batch Endianness Swap)
当与上位机通讯发现数值乱码（如负数极大或浮点数溢出）时，通常是字节序不匹配导致，您可快速批量修正变位：
1. **多选点位**：
   - 按住 `Ctrl` 键逐个点击目标点位；
   - 或按住 `Shift` 键连续范围多选；
   - 或按 `Ctrl + A` 选中整个表格的所有点位。
2. **执行批量变位**：
   - 点击顶部工具栏的 **【批量变位】** 下拉菜单，或在选中区域**右键点击【批量修改变位】**；
   - 选择目标模式（例如将选中的所有点位一键从 `ABCD` 转换为 `CDAB`）；
   - **生效机制**：系统将自动保留当前工程数值，重新计算该变位模式下的寄存器字节分布，实现批量无损变位。

### 5.3 跨从机批量范围选择 (当前从机 vs 全部从机服务)
当系统配置了多个从机服务实例（例如不同 IP:Port 的储能设备、PCS、电表从机）时，无需繁琐地逐个切换从机：
1. **适用范围切换**：在批量工具栏前端选择：
   - `🔘 仅当前从机`：仅作用于当前所选的从机服务实例（如未选具体行，系统会友好提示是否作用于当前从机全部点位）。
   - `⚪ 全部从机服务`：一键向系统中所有已注册的从机服务实例广播生效！
2. **支持操作**：
   - **⚡ 批量修改规则**：一键将所有从机服务的点位全部置为“随机波动”、“累加递增”或恢复“固定”。
   - **批量修改变位 / 类型 / 数值**：一键完成全从机统一变位模式或赋初值。

### 5.4 动态模拟规则机制 (FC 01/02 与 FC 03/04 的区别)
- **FC 01 (线圈) 与 FC 02 (离散输入)**：
  - 作为 1 位开关量，只要配置了模拟规则（非“固定”），数值自动且严格在 `0` 和 `1` 之间交替变动，**不受模拟规则数学公式限制**。
- **FC 03 (保持寄存器) 与 FC 04 (输入寄存器)**：
  - 严格受所选模拟规则（累加递增、正弦波、随机波动等）控制，并与数据类型（UINT16/FLOAT32/INT64 等）合法值域强关联，绝不会产生负数下溢或异常爆大。

## 6. 工业级变位模式详解

针对 32 位（4 字节，如 FLOAT32、INT32、UINT32）及 64 位类型，字节与字的排列顺序对于数值还原至关重要：

| 变位模式代号 | 工业界通俗别名 | 4 字节原始顺序对应 | 典型应用硬件与场景 |
| :--- | :--- | :--- | :--- |
| **ABCD** | Big-Endian (大端) | Byte 1, Byte 2, Byte 3, Byte 4 | 标准网络字节序、部分西门子/欧姆龙 PLC |
| **CDAB** | Little-Endian Word Swap | Byte 3, Byte 4, Byte 1, Byte 2 | **国内多数储能 PCS、BMS、智能电表最常用** |
| **BADC** | Little-Endian Byte Swap | Byte 2, Byte 1, Byte 4, Byte 3 | 部分特殊串行仪表与 Modbus 转换网关 |
| **DCBA** | True Little-Endian (纯小端) | Byte 4, Byte 3, Byte 2, Byte 1 | x86 架构原生内存布局、部分专用控制器 |

> 💡 **排查技巧**：若读取出来的 32 位浮点数显示为非正常数值（例如本应为 220.0，却显示为 $1.23 \times 10^{-38}$ 或乱码），通常仅需使用“批量变位”在 `ABCD` 与 `CDAB` 之间进行一键切换即可正常还原。

## 7. HEMS 业务数据库联动与修改关联数据库

软件内置对 SQLite 格式（如 `hems.cdb`）业务数据库的解析与配对能力。您可以非常方便地切换或修改关联的目标数据库。

### 7.1 如何修改 / 切换关联的数据库？

软件为您提供了 **三种灵活的修改方式**：

#### 🌟 方式一：在软件界面中一键切换 (最推荐，即选即用)
1. **主界面切换**：在 Slave 模拟器顶部控制栏，点击 **【🗃️ 关联/切换数据库...】** 按钮。
2. **弹窗内切换**：打开【📂 导入设备点表】或【🔗 业务配对中心】对话框，在顶部右侧均提供了 **【📂 浏览更换数据库...】** 按钮。
3. **文件选择**：在弹出的文件浏览器中，选择您电脑上任意目录的 `.cdb`、`.sqlite` 或 `.db` 数据库文件。
4. **即刻生效**：系统会自动重新扫描并解析新库中的 `app` 表配置，并弹出提示告知识别到的 Modbus 设备数量，无需重启软件。

#### 📁 方式二：文件覆盖替换 (免改动任何设置)
- 如果您的业务数据库更新了，只需将新的数据库文件复制到项目的 `extra/` 目录下，并重命名为 **`hems.cdb`** 直接覆盖旧文件即可。

#### 💻 方式三：直接修改源码默认路径 (二次开发场景)
- 打开 [`modbus_studio.py`](file:///f:/GitHub/python/modbus_studio.py) 文件，定位至约第 71 行：
  ```python
  # 修改括号内的默认数据库路径即可
  self.hems_db = HemsDatabase(os.path.join("extra", "hems.cdb"))
  self.pairing_engine = HemsPairingEngine(self.hems_db.db_path)
  ```

### 7.2 查看与导入业务设备（严格类型权限规则）

系统严格遵循业务划分规范，实施导入控制：

| 数据库 app 表类型 | 业务角色定位 | 允许导入的模块 | 限制说明 |
| :--- | :--- | :--- | :--- |
| **Type = 1** | **南向采集端设备** (BMS, 功率计, PCS, 外部设备等) | **✅ 仅限 Slave 从机模拟器** | 用于在上位机测试中模拟真实的物理硬件 |
| **Type = 2** | **北向通信应用** ([North]30 Modbus 服务, MQTT 等) | **✅ 仅限 Poll 主机调试器** | 用于模拟网关或调度主站轮询该服务节点 |
| **Type = 0 / 3** | **内部系统 / 策略计算模块** | **❌ 禁止导入** | 非 Modbus 物理点表，界面自动置灰锁定 |

#### 导入与多 IP/多端口监听操作流程：
1. 点击顶部控制栏的 **【📂 导入设备点表...】**。
2. 表格清晰呈现各设备的 `Type`、`导入权限限制` 以及从 `Local Parameters` 中解析的 `网络配置(IP:Port)`。
3. **快捷多选与一键全选**：
   - 支持按住 `Ctrl` 或 `Shift` 键进行**批量多选**；
   - 顶部快捷操作栏提供专用筛选按钮：
     - **【☑️ 全选已启用 Slave (Type=1)】**：只勾选状态为【已启用】且业务类型为 Slave 的从机设备；
     - **【☑️ 全选已启用 Poll (Type=2)】**：只勾选状态为【已启用】且业务类型为 Poll 的主机应用；
     - **【⬜ 清空选择】**：一键取消全部高亮选中状态。
   - 对话框支持上下拉伸：向下拉伸窗口时，仅中间点表表格自适应扩展，顶部说明栏与快捷操作栏保持固定高度。
4. **批量/单项导入为从机 (Type=1)**：
   - 选中一个或多个 Type=1 设备后，点击下方 **【📥 导入为 Slave 从机仿真服务】**；
   - 系统将询问：**是否为选中的设备创建【各自独立的从机服务实例】？**
     - **选择【是】**：系统将批量为每台选中的设备建立独立的服务实例（如 `从机[BMS] (10003)`、`从机[功率计] (10001)`），自动配置其独立专属的端口；
     - **选择【否】**：将所有选中的设备点表合并导入到当前从机服务实例中。
   - **多端口并发监听**：在主界面顶部控制栏点击 **【⚡ 全部启动】**，即可同时在各个独立的 IP 和端口上并发监听通信！
5. **导入为主机轮询 (Type=2)**：
   - 选中 Type=2 应用（如 `[North]30`）。
   - 下方【📡 导入为 Poll 主机轮询目标】按钮自动高亮（Slave 按钮自动禁用）。
   - 点击后系统自动将该服务的目标 IP 与端口（如 `127.0.0.1:9000`）及轮询规则填入 Poll 调试器中。

### 7.3 日志面板与通信报文监控使用指南
- **上下拖拽拉伸高度**：
  - 主界面与底部日志区域之间设有分割栏，鼠标悬停至分割条处按住左键，可**上下自由拖动拉伸调整日志区域的高度比例**。
- **日志复制与粘贴**：
  - **右键菜单**：在日志区域点击鼠标右键，支持【复制】、【粘贴】、【全选】、【清空日志】、【导出为 CSV 文件...】；
  - **键盘快捷键**：支持标准的 `Ctrl+C`（复制选中文本）、`Ctrl+V`（粘贴到光标处）、`Ctrl+A`（全选全部文本）。
- **问询与响应报文实时高亮打印 (同时支持 Slave 与 Poll)**：
  - 勾选【显示问询与响应报文】后，系统在通讯发生时毫秒级实时打印报文帧：
    - **Slave 从机模式**：当外部任何上位机/网关向本机从机端口发送问询时，实时捕获并打印 **`[RX 问询报文]`**（包含从机 ID、功能码 01/02/03/04/05/06/15/16 语义、寄存器地址、数量及 HEX 报文帧），并随后打印回复的 **`[TX 从机响应]`**（包含字节数、寄存器数值预览与 HEX 帧）。
    - **Poll 主机模式**：向外部从机发送读取/写入指令时，实时打印 **`[TX 问询报文]`** 与接收到的 **`[RX 响应报文]`**。
- **一键导出与后台自动实时落盘**：
  - **自动实时落盘**：软件启动后自动在 `logs/` 目录按日期生成 `modbus_runtime_YYYYMMDD.csv`，每当收发一条报文或产生一条系统状态，立即实时追加落盘（具备写缓冲 flush 机制），彻底防止异常退出或断电丢日志；点击日志栏的 **【📂 打开日志目录】** 即可直接查看。
  - **手动自由导出**：点击日志工具栏的 **【💾 导出CSV】** 按钮或通过右键菜单选择【导出为 CSV 文件...】；可随时将历史记录另存为指定路径的标准 CSV 文件。

### 7.4 工业 44 种数据类型体系与动态模拟安全防溢
- 系统原生支持工业标准的 **44 种数据类型字典**（包含 Bit、Short 1~2、Int 1~4、Int64 1~8、Float 1~4、Double 1~8 等），支持根据协议编号或中英文名称精准识别并自动适配对应的字序与字节序（ABCD / BADC / CDAB / DCBA）。
- **动态模拟强关联数据类型**：彻底治理无符号整型（UINT16/UINT32/UINT64）在随机波动时产生负数下溢爆大成 42.9 亿的问题，所有类型在动态生成与写入时均通过严格的值域范围安全钳位，确保数值平滑、真实且完全合规。

### 7.4 点表输入默认状态
- 为保证调试工作的整洁与高效，启动软件时**测点添加区域（地址、描述、初始值）及点位表格均默认置空**，不再预填演示样例，方便用户根据实际项目导入或手工录入。

### 7.5 南向-北向配对推演 (`More` 字段联动)
- 在控制栏点击 **【🔗 业务配对中心 (基于 More)...】**。
- 引擎根据各设备 `More` 属性中配置的数据流映射关系，自动分析南向电表/储能的物理量对应映射到北向 `[North]30` 的哪个保持寄存器。
- 支持直接模拟南向变位，实时观测北向寄存器的联动变化。

## 8. 重新编译与打包说明

若您自行修改了 Python 源码，需要重新生成 EXE：
1. 确保已在虚拟环境中安装所需依赖（`pymodbus`, `pillow`, `pyinstaller`）。

## 9. 常见问题排查 (FAQ)

### Q1: 启动 Slave 提示“端口 502 绑定失败”或“权限不足”？
- **原因**：在 Windows 系统中，低于 1024 的知名端口可能需要管理员权限，或者当前电脑上有其他 Modbus 软件（如 Modbus Poll/Slave 破解版或本地后台服务）占用了 502 端口。
- **解决办法**：
  1. 将端口修改为 `1502` 或 `5020` 等高位端口；
  2. 或以“管理员身份运行”本软件；
  3. 或在任务管理器中关闭占用 502 端口的冲突进程。

### Q2: 为什么双击 dist/ModbusStudio.exe 没有弹出黑色控制台？
- **解答**：打包时默认采用了 `--windowed`（无黑框 GUI 模式），提供整洁的现代软件体验。软件内部所有日志和通信报文都会实时显示在主界面底部的“底层日志与报文监控区”中。

### Q3: 批量修改变位会改变原本的物理数值吗？
- **解答**：不会。软件的批量变位算法是**保持工程值不变，重新对底层 16 位寄存器数组进行字节重新排列**。转换后上位机以新的变位模式读取时，解析出的工程数值将完全一致。
