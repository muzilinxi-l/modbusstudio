## 3. 从机模拟 (Modbus Slave) 使用指南

当您需要模拟实际的硬件 PLC、智能电表或储能设备，供上位机（SCADA、EMS 系统或网关）采集测试时，使用此模式。

### 操作步骤：
1. **确认工作模式**：顶部选择 **【Modbus Slave (从机模拟器)】**。
2. **设定通信参数**：
   - **监听 IP**：默认 `0.0.0.0`（监听所有网卡）或 `127.0.0.1`（仅本机回环）。
   - **端口**：默认为标准 Modbus 端口 `502`（如遇到权限或占用冲突可改为 `1502`、`5020` 等）。
   - **从机 ID (Unit ID)**：根据测试需求设置（通常为 `1` ~ `247`）。
3. **添加或编辑点位**：
   - 点击 **【+ 添加点位】** 按钮，弹出添加窗口：
     - **存储区**：保持寄存器 (Holding)、输入寄存器 (Input)、线圈 (Coil)、离散输入 (Discrete)。
     - **起始地址**：寄存器偏移地址（如 `0`、`100` 等）。
     - **数据类型**：选择如 `FLOAT32`、`UINT16`、`INT32` 等。
     - **变位模式**：选择匹配的字节序（如 `CDAB`）。
     - **初始值**：输入预期的工程值（如 `220.5`）。
4. **启动从机服务**：
   - 点击 **【启动从机】** 按钮。状态栏显示绿色“服务运行中”，此时任何外部 Modbus Master 均可连接并读取写入数据。
5. **动态修改数值**：
   - 在数据表格中**双击目标行**，即可实时修改数值，底层从机 Context 将毫秒级同步更新。

## 4. 主机调试 (Modbus Poll) 使用指南

当您需要调试外部已有的物理设备或第三方 Modbus 从机服务时，使用此模式。

### 操作步骤：
1. **切换模式**：顶部单选框切换为 **【Modbus Poll (主机轮询器)】**。
2. **设定目标参数**：
   - 输入目标设备的 **IP 地址** 与 **端口**。
   - 输入目标 **从机地址 (Slave ID)**。
   - 设定 **轮询周期**（如 `1000 ms`）。
3. **点击【连接从机】**：
   - 连接成功后，轮询引擎会按照表格中配置的点位地址与数据类型，周期性发出读取指令。
4. **在线向从机写入数据**：
   - 选中表格中某一点位，右键选择 **【写入数值】**，输入目标数值后确认，主机引擎将组装功能码（如 0x06、0x10）写入目标从机。

## 5. 批量操作指南 (点位生成与批量变位)

在实际工程场景中，点位通常成百上千，手动单个录入极耗时间。Modbus Studio 提供了强大的批量处理体系：

### 5.1 批量规则生成器 (Batch Rule Generator)
- **触发入口**：点击工具栏的 **【批量规则生成】** 按钮。
- **输入参数**：
  - **存储区**：选择寄存器类型（如保持寄存器）。
  - **起始地址**：如输入 `0`。
  - **点位数量**：如输入 `20`。
  - **地址步长**：若选择 32 位类型（占用 2 个寄存器），建议步长设为 `2`；16 位类型设为 `1`。
  - **数据类型**：如 `FLOAT32`。
  - **变位模式**：如 `CDAB`。
  - **点位前缀**：如 `Point_`（将自动生成 Point_0, Point_1...）。
  - **初值与递增量**：设置基础初始值及每个点位的累加递增量。
- **确认生成**：点击生成后，系统将在瞬间自动输出所有计算好的点位并写入底层模拟引擎。

### 5.2 多选与批量变位修改 (Batch Endianness Swap)
当与上位机通讯发现数值乱码（如负数极大或浮点数溢出）时，通常是字节序不匹配导致，您可快速批量修正变位：
1. **多选点位**：
   - 按住 `Ctrl` 键逐个点击目标点位；
   - 或按住 `Shift` 键连续范围多选；
   - 或按 `Ctrl + A` 选中整个表格的所有点位。
2. **执行批量变位**：
   - 点击顶部工具栏的 **【批量变位】** 下拉菜单，或在选中区域**右键点击【批量修改变位】**；
   - 选择目标模式（例如将选中的所有点位一键从 `ABCD` 转换为 `CDAB`）；
   - **生效机制**：系统将自动保留当前工程数值，重新计算该变位模式下的寄存器字节分布，实现批量无损变位。

## 6. 工业级变位模式详解

针对 32 位（4 字节，如 FLOAT32、INT32、UINT32）及 64 位类型，字节与字的排列顺序对于数值还原至关重要：

| 变位模式代号 | 工业界通俗别名 | 4 字节原始顺序对应 | 典型应用硬件与场景 |
| :--- | :--- | :--- | :--- |
| **ABCD** | Big-Endian (大端) | Byte 1, Byte 2, Byte 3, Byte 4 | 标准网络字节序、部分西门子/欧姆龙 PLC |
| **CDAB** | Little-Endian Word Swap | Byte 3, Byte 4, Byte 1, Byte 2 | **国内多数储能 PCS、BMS、智能电表最常用** |
| **BADC** | Little-Endian Byte Swap | Byte 2, Byte 1, Byte 4, Byte 3 | 部分特殊串行仪表与 Modbus 转换网关 |
| **DCBA** | True Little-Endian (纯小端) | Byte 4, Byte 3, Byte 2, Byte 1 | x86 架构原生内存布局、部分专用控制器 |

> 💡 **排查技巧**：若读取出来的 32 位浮点数显示为非正常数值（例如本应为 220.0，却显示为 $1.23 \times 10^{-38}$ 或乱码），通常仅需使用“批量变位”在 `ABCD` 与 `CDAB` 之间进行一键切换即可正常还原。

## 7. HEMS 业务数据库联动与配对

软件内置对 `extra/hems.cdb`（SQLite 格式）业务数据库的自动化解析能力。

### 7.1 查看与导入业务设备
1. 点击顶部菜单栏的 **【业务数据库 (hems.cdb)】** -> **【扫描与加载设备】**。
2. 系统自动解析 `app` 表中的所有设备分类：
   - **南向采集端**：
     - `FDDSL600`：多功能电表点表
     - `FDDFJFH`：房间负荷控制器
     - `BMS`：电池管理系统
     - `PCS`：储能变流器
   - **北向服务端口**：
     - `[North]30`：系统对外统一转发 Modbus 节点
3. 点击 **【一键导入为 Slave 点表】**：系统自动将业务数据库中预先配置好的真实测点、缩放倍率（Scale）、起始地址导入到工作台中，免去人工重录。

### 7.2 南向-北向配对推演 (`More` 字段联动)
- 在菜单中点击 **【南向/北向自动配对分析】**。
- 引擎根据各设备 `More` 属性中配置的数据流映射关系，自动分析南向电表/储能的物理量对应映射到北向 `[North]30` 的哪个保持寄存器。
- 支持直接模拟南向变位，实时观测北向寄存器的联动变化。

## 9. 常见问题排查 (FAQ)

### Q1: 启动 Slave 提示“端口 502 绑定失败”或“权限不足”？
- **原因**：在 Windows 系统中，低于 1024 的知名端口可能需要管理员权限，或者当前电脑上有其他 Modbus 软件（如 Modbus Poll/Slave 破解版或本地后台服务）占用了 502 端口。
- **解决办法**：
  1. 将端口修改为 `1502` 或 `5020` 等高位端口；
  2. 或以“管理员身份运行”本软件；
  3. 或在任务管理器中关闭占用 502 端口的冲突进程。

### Q2: 为什么双击 dist/ModbusStudio.exe 没有弹出黑色控制台？
- **解答**：打包时默认采用了 `--windowed`（无黑框 GUI 模式），提供整洁的现代软件体验。软件内部所有日志和通信报文都会实时显示在主界面底部的“底层日志与报文监控区”中。

### Q3: 批量修改变位会改变原本的物理数值吗？
- **解答**：不会。软件的批量变位算法是**保持工程值不变，重新对底层 16 位寄存器数组进行字节重新排列**。转换后上位机以新的变位模式读取时，解析出的工程数值将完全一致。
